# 接入大模型：能做什么（方案草稿）

> 状态：提案 v0 · 2026-10-15 · 对应需求 R42（见 [requirements.md](requirements.md)）。还没有确认，等你选定范围和模型服务商后再细化。

## 1. 为什么 golauncher 适合接大模型

- **它本来就是"一句话 → 一个动作"的入口**：按 Alt+Space 输入一句话，正好就是向大模型提问的姿势。
- **插件系统就是现成的工具清单**：每个插件的命令和动作都有标题、参数，类型也明确（`ActionDo`）。破坏性的动作已经标了 `Destructive`，宿主会统一弹确认框。把它们暴露给模型作为工具（function calling），模型就能"替你点按钮"，而且危险操作仍然要你确认。
- **有环境感知**（R25）：知道当前的 Explorer 文件夹和选中的文件，可以作为上下文发给模型。
- **有推送式渲染**（`Host.Render`）和后台任务：适合流式显示回答，以及跑耗时的多步任务。

## 2. 能做什么（按价值和难度排列）

### 2.1 快速问答（Quick AI）

- 输入任意问题，按 `Tab`，或者在没有好结果时选"Ask AI"，在详情面板里**流式**显示回答。
- 可以接着追问，形成对话。回答可以复制、粘贴到前一个窗口，或存进剪贴板历史。
- 只在你明确触发时才调用模型，**打字过程中从不调用**（省钱、不泄露、不拖慢搜索）。

### 2.2 AI 命令（对文本做事）

- 对**选中的文本或剪贴板内容**执行预设的提示词：翻译（中↔英）、润色、改写语气、总结、解释代码、修语法、生成提交说明、表格转 Markdown……
- 结果可以直接粘贴回原来的窗口，替换选中的文本。
- 你可以自己写命令，提示词模板里能用 `{selection}`、`{clipboard}`、`{argument}` 等变量。每条命令都是普通命令，可以设别名和全局快捷键。这对应 Raycast 的 AI Commands。

### 2.3 自然语言操作启动器（Agent，调用插件）

- 例如：
  - "东京现在几点，和北京差几个小时" → 世界时钟；
  - "把 WSL 关了" → 终端插件；
  - "升级所有 winget 软件" → WinGet 插件，弹确认框；
  - "8080 端口被谁占了" → 网络工具；
  - "打开蓝牙设置" → 设置直达。
- 实现上，每个插件的命令和动作转成工具描述交给模型，模型选择并填参数，宿主执行。破坏性动作照旧确认，长任务进后台任务。
- 第三方插件只要按 SDK 写，就自动获得这个能力，**插件作者不用为 AI 写任何代码**。

### 2.4 结合环境感知

- 在 Explorer 里：
  - "总结这个文件夹里的文档"；
  - "这个文件是什么"（选中一个文件）；
  - "把这些照片按日期重命名"：模型先给出计划，你确认后执行。
- 发给模型的内容会先列出来（哪些文件名、哪些文件内容），默认不自动附带。

### 2.5 更聪明的搜索

- 搜索结果很差时，用模型理解意图：例如"改壁纸"→ 个性化 › 背景设置页，"电脑卡"→ 任务管理器、资源监视器。
- 也可以先用**本地的向量模型**给设置页和命令做语义索引，不联网、不花钱。可以作为后续一步。

### 2.6 剪贴板历史和计算器的增强

- 按意思搜剪贴板历史："上周复制的那个快递单号"；从剪贴板内容里提取信息（地址、电话、日期）。
- 用自然语言算东西："一年后 5 万存款按 2.1% 利息是多少"。现有的计算器能算的仍然本地算，算不了的才交给模型。

### 2.7 和其他 Agent 互通（MCP）

- **作为 MCP 服务器**：把 golauncher 的插件（应用、文件搜索、WinGet、终端、系统设置……）通过 MCP 暴露给 Claude Code、Claude Desktop 等 Agent 使用。`glctl` 已经是给 Agent 用的 CLI，这是它的自然延伸。
- **作为 MCP 客户端**：AI 对话里可以调用你配置的 MCP 服务器，例如 GitHub、日历、笔记。

## 3. 设计要点

- **模型服务商可选**：
  - Anthropic（Claude）；
  - OpenAI 兼容接口，覆盖 OpenAI、DeepSeek、通义千问、Kimi、智谱、硅基流动等；
  - 本地的 Ollama / LM Studio。

  做成一个 `ai` 抽象层，插件通过 SDK 的新接口（如 `Host.AI()`）调用，不直接访问网络。
- **API Key**：存进 Windows 凭据管理器（已有的 `password` 偏好机制），不进 `config.json`。
- **隐私**：默认什么都不自动发送；附带的上下文（选中文本、文件、剪贴板）在发送前可见。剪贴板历史里标为敏感的内容（例如密码，见 R37 的 `WriteSecret`）永远不发。提供"只用本地模型"的开关。
- **流式与取消**：回答通过 `Host.Render` 流式推送；按 Esc 或关闭视图就取消请求。
- **测试**：`glctl` 的假环境里用脚本化的假模型（固定回答和工具调用序列），不联网、可重复；真实调用只在设了环境变量时运行。
- **费用和用量**：设置里显示本月的调用次数和 token 数，可以设上限。

## 4. 建议的分期

| 阶段 | 内容 | 说明 |
|------|------|------|
| 一 | `ai` 抽象层（Anthropic、OpenAI 兼容、Ollama）+ 快速问答（2.1）+ AI 命令（2.2） | 价值最高、风险最低，不涉及替你执行操作 |
| 二 | Agent 调用插件（2.3）+ 结合环境感知（2.4） | 需要设计工具描述、确认流程、多步计划的界面 |
| 三 | MCP 服务器/客户端（2.7）、语义搜索（2.5）、剪贴板和计算器增强（2.6） | 按需要挑着做 |

## 5. 需要你决定

1. 先做哪些（建议从第一阶段开始）。
2. 主要用哪家的模型？是否需要国内服务商，或者本地模型？
3. 默认的触发方式：`Tab` 进入 AI，还是只在没有结果时显示"Ask AI"，还是两者都要。
