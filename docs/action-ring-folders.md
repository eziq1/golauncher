# Action Ring 目录方案

> 状态：方案 v1 · 已确认（§3 四项都按建议执行），已实现（§4，待合并） · 2026-10-22 · 对应需求 R118（见 [requirements.md](requirements.md)）
>
> 需求：增加 Action 目录：拖动一个 Action 叠到另一个上面，组成目录；鼠标移到目录上时，展开一个小的圆弧菜单。

## 1. 用起来的样子

**使用**（按住中键弹出圆环后）：

```
                  [1 打开 golauncher]
            ⌘
   📁 工具 ▸          >_  ─┐
                           │  ┌ ① 截图
  🔒        ×        ✨    ├──┤ ② 取色
                           │  └ ③ 录屏
          ...              ┘   ← 指向"工具"目录时，在它外侧展开的小圆弧
```

- 目录在圆环上占一格。图标是里面前几个操作的小图标拼成的 2×2 缩略图（像手机桌面的文件夹），标签显示目录名和一个 ▸。
- 鼠标或拖动方向**停在目录上约 150 毫秒**，就在这个目录的外侧展开一段小圆弧，排着目录里的操作（最多 6 个），每个也带标签。
- 小圆弧的选法和主圆环一样：
  - 按住中键拖动：先拖到目录，等小圆弧展开，继续往外拖到某个操作上松开；
  - 圆环停在屏幕上时：指向目录展开，再点里面的操作；键盘上按目录的数字键展开，再按 1–6 选择；
  - 指针移回主圆环、移到别的格子，或按 Esc，小圆弧就收起。
- 小圆弧靠近屏幕边缘放不下时，自动换到另一侧展开。

**编辑**（设置 › Action Ring 的"固定操作"一节，改成一个可视化的圆环编辑器）：

- 编辑器画出和真实圆环一样的 8 个格子，可以直接拖动：
  - 把一个操作**拖到空格子**：移动它；
  - 拖到另一个操作上，**停留约 0.5 秒**（那个格子会放大提示）再松开：两个合成一个新目录，默认名"目录"，可以改名；
  - 拖到**已有目录**上：放进这个目录；
  - 点开目录，在目录里拖动：调整顺序；把操作**拖出目录**：放回圆环的空格子（没有空格子时不允许）；
  - 目录只剩一个操作时，自动解散成普通操作。
- "添加操作"按钮和现在一样，可以加到空格子里，也可以直接加进某个目录。
- 不方便拖动时也能用键盘：选中格子后，用按钮完成"移动""放入目录""移出目录"。

## 2. 规则

| 项 | 规则 |
|---|---|
| 层级 | 只有一层：目录里不能再放目录 |
| 每个目录最多 | 6 个操作（圆弧再长会挤，选起来容易误触） |
| 能放进目录的 | 固定操作。情境操作（选中文字、资源管理器相关）每次弹出都不一样，不能放进目录 |
| 情境操作的位置 | 不变：固定操作（含目录）占上下左右 4 格，情境操作占斜向 4 格。目录也算一个固定操作，所以最多 4 个"固定的格子"，每格可以是一个操作或一个目录 |
| 目录名 | 默认"目录"，在编辑器里点名称改；圆环上的标签显示名称 |
| 存储 | 存在 `config.json` 的 `ring` 里：固定格子从"操作 ID 列表"改成"格子列表"，每格是一个操作或一个目录（名称 + 操作 ID 列表）；旧配置自动迁移 |

## 3. 需要你决定

1. 情境操作不能放进目录，目录只有一层、每个最多 6 个操作，可以吗？
2. 固定格子维持 4 个（上下左右），每格可以是操作或目录，可以吗？还是希望能把 8 个格子都设成固定的（不要情境操作）？
3. 编辑放在设置页的可视化圆环编辑器里，可以吗？还是希望在真实的圆环上（比如按住某个键）直接拖？后者要处理"圆环不抢焦点"和拖动的冲突，复杂很多，我不推荐。
4. 停留多久展开：小圆弧 150 毫秒、编辑器里合成目录 0.5 秒，可以吗？

## 4. 实现记录（2026-10-22）

按 §1、§2 做完，§3 四项按建议。

### 4.1 代码在哪

| 部分 | 位置 |
|---|---|
| 配置：格子（操作 / 目录 / 空）、迁移和校验 | `internal/config/config.go`：`RingSlot`、`NormalizeRingFixed`、`MaxRingFixed = 4`、`MaxRingFolder = 6` |
| 圆环内容：固定格子按位置、目录、情境操作 | `internal/ring/build.go`（`FixedSlots`）、`internal/ring/slots.go`（`Arrange`、`Assemble`） |
| 小圆弧的排布、躲开屏幕边缘、按角度和半径分区选中 | `internal/ring/geometry.go`：`LayoutArc`、`Arc.ItemAt`、`Pick`、`PlaceAround` |
| 编辑器的各种改动（纯函数） | `internal/ring/edit.go`：`Fixed` 的 `Move`、`Merge`、`AddToFolder`、`Reorder`、`MoveOut`、`MoveInto`、`DeleteFolder`、`Add`… |
| 圆环界面：目录格、停留展开、小圆弧 | `internal/ui/ring.go` |
| 设置页的圆环编辑器 | `internal/ui/settings_ring_editor.go`、`internal/ui/settings_ring.go` |

### 4.2 配置和迁移

- `ring.fixed` 是格子列表，按位置排：上、右、下、左。操作格照旧写成 `{"key", "title", "icon"}`（和以前的操作一模一样，所以旧文件直接读成格子）；目录写成 `{"name", "actions": [...]}`；空格子写成 `{}`。末尾的空格子不写。
- 读配置时校验：没有 key 的操作、重复的 key 去掉；空目录变成空格子；只剩一个操作的目录变成这个操作；目录最多 6 个，多的去掉。不认识的操作照旧保留在配置里，圆环显示时跳过。
- **旧配置超过 4 个固定操作**（以前最多 8 个，后 4 个占斜向）：第 5 个起和第 4 个一起放进左边格子的一个目录（名称为空，显示为“目录”），一个都不丢（**方案没说**）。
- 恢复默认：4 个操作，没有目录。
- 旧版本读新配置：目录格和空格子会被当成找不到的操作（显示为空标题），不会出错。

### 4.3 圆环上

- 目录格：图标是前 4 个操作的小图标 2×2 拼起来；标签是目录名加一个 ▸；名称为空时显示“目录”。
- 指针悬停或拖动方向停在目录上 **150 毫秒**展开小圆弧（界面用 MyGo 的帧时钟 `c.Now()` 计时、`c.After` 到点重画，测试用 `Tester.Advance`）；点目录或它的标签、按目录的数字键立即展开。
- **小圆弧**：子格直径 40，圆心离圆环中心 170，相邻两个相隔 30°，以目录方向为中心排开（最多 6 个，跨 150°）。每个子格都有始终显示的标签（带 1–6 数字键）：右半边的标签在子格右边，左半边的在左边，正上方 / 正下方的在上面 / 下面居中，这样标签之间、标签和子格之间都不重叠。
- **屏幕边缘**：放不下时按 30° 一步往两边转（先近后远，最多 90°），还不行就翻到圆环另一侧；都放不下时选超出最少的。
- **窗口**：有目录时窗口加大到 776×468 DIP（没有目录时仍是 652×344）。定位时只把**圆环本身**（652×344 那一块）推回工作区，窗口以圆环为中心，可以超出屏幕；小圆弧只在窗口落在工作区里的那部分排布（**和方案的出入**：方案只说“换到另一侧”）。窗口仍是 R117 的透明 Flyout（macOS 仍是 Panel）。
- 小圆弧展开时，圆环上和小圆弧重叠的标签暂时隐藏（**方案没说**），否则会叠在一起。
- **选择**：
  - 按住中键拖到目录，等小圆弧展开，继续往外拖：离中心超过圆盘半径（126）后按角度选子格（每个子格左右各 15°），松开执行；松开在目录上（没选子格）不执行，圆环留下、小圆弧开着。
  - 圆环停在屏幕上时：悬停或点目录展开，点子格或它的标签执行；中键点子格也执行。
  - 数字键：目录的数字键展开，再按 1–6 选；Esc 先收起小圆弧，再按一次关圆环。
  - 指针或拖动方向移到别的格子、中间的关闭按钮，或拖回中心死区，小圆弧收起。指针停在空白处不收起（容易移过去）。
- 小圆弧没有展开动画（**和方案的出入**，圆环本身的打开动画不变）。
- 固定格子空着时，情境操作先占斜向 4 格，再占空着的主方向格子（和以前一样不留空）。

### 4.4 设置页的圆环编辑器

- “固定操作”一节换成一个画出来的圆环：上下左右 4 个格子（操作的图标 / 目录的 2×2 缩略图 / 空格子的 +），名称写在格子下方；斜向 4 格是灰色的“情境”。整个编辑器是一个 `HandleInput` 元素，自己处理按下、移动、松开（移动超过 4 DIP 才算拖动），拖动的东西跟着指针走。
- 拖动操作：
  - 到空格子：移过去；
  - 到另一个操作上，**停留 0.5 秒**（那个格子放大到 1.18 倍提示）再松开：合成新目录，名称“目录”（按界面语言），目录在下方打开，名称输入框获得焦点可以直接改名；**不到 0.5 秒就松开：两个交换位置**（**方案没说**）；
  - 到目录上：放进目录末尾；目录已满（6 个）时不放，提示“这个目录满了”；
  - 拖目录到别的格子：移动 / 交换（目录不能放进目录）。
- 点目录：在圆环下方打开一条，排着它的操作（带序号）；在这里拖动调整顺序；拖到圆环的空格子上就移出目录；拖到另一个目录上就移进那个目录；拖到操作上提示“拖到空格子上才能移出目录”，没有空格子时提示“没有空格子”。目录剩一个操作时自动解散成这个操作。目录在圆环下方打开，**没有画成小圆弧**（**和方案的出入**，横排更好拖动排序）。
- 改名：目录打开时下方有“目录名称”输入框。
- 键盘 / 不方便拖动时：选中格子（点一下）后下方出现按钮：
  - 操作：“移动…”（选上 / 右 / 下 / 左，有东西就交换）、“放入目录…”（放进已有目录，或和另一个操作合成新目录；满的目录灰掉）、“移除”；
  - 目录：“移动…”、“删除目录”；
  - 目录里的操作：“移动…”（选第几个）、“放入目录…”、“移出目录”（到第一个空格子）、“移除”。
- 删除目录：里面的操作先放回它自己的格子，再放到其他空格子；放不下时先问（“空格子只放得下其中 N 个操作，其余的会被移除”）。
- “添加操作”：选中的是空格子或没满的目录时加到那里，否则加到第一个空格子；没有空格子也没有可加的目录时按钮不可用。已在圆环或任何目录里的操作显示“已添加”。
- “恢复默认”照旧先确认。

### 4.5 测试

- 配置：旧格式（操作列表、8 个操作、中间有空）迁移；校验规则（空目录、一个的目录、超过 6 个、重复、目录名只留给目录）；写回再读；`Clone` 不共享目录。
- 几何：4 个方向、2–6 个子格的排布（在圆上、居中、标签朝外、互不重叠）；靠右 / 左 / 上 / 下边、右上角时转开并放得下；放不下时翻到另一侧；`Pick` 的死区、主圆环、小圆弧的角度和半径分区、小圆弧两端以外。
- 编辑的纯函数：移动、交换、合成、放入、已满、排序、移出、没有空格子、移入别的目录、自动解散、改名、删除目录（放得下 / 放不下）、添加。
- 圆环界面（`mui.Tester`）：悬停 150ms 才展开（100ms 时没有）、子格和标签都显示、移到别的格子收起、点目录立即展开、点子格执行；数字键展开再选、超出个数不响应、Esc 先收小圆弧再关圆环、收起后不会马上又展开；拖动到目录 150ms 展开、继续拖到子格松开执行、松开在目录上留下并展开、拖向别的格子收起、中键点子格执行。
- 编辑器（`mui.Tester`，按下 / 移动 / 松开）：拖到空格子移动；停留 0.5 秒合成目录（并打开、改名）；不到 0.5 秒交换；拖进目录；目录里排序；拖出到空格子；剩一个自动解散；目录已满的提示；没有空格子的提示；各个按钮（移动、合成新目录、放入目录、移出目录、目录内移动、移除、删除目录及确认）；添加到选中的空格子；恢复默认；中文。
- 真实的拖动手感、小圆弧在屏幕边缘的位置、窗口超出屏幕时透明区域的表现，**需要在 Windows 和 macOS 上实测**。
