# Action Ring 目录方案

> 状态：方案 v1 · 待你 review · 2026-10-22 · 对应需求 R118（见 [requirements.md](requirements.md)）
>
> 需求：增加 Action 目录：拖动一个 Action 叠到另一个上面，组成目录；鼠标移到目录上时，展开一个小的圆弧菜单。

## 1. 用起来的样子

**使用**（按住中键弹出圆环后）：

```
                  [1 打开 golauncher]
            ⌘
   📁 工具 ▸          >_  ─┐
                           │  ┌ ① 截图
  🔒        ×        ✨    ├──┤ ② 取色
                           │  └ ③ 录屏
          ...              ┘   ← 指向"工具"目录时，在它外侧展开的小圆弧
```

- 目录在圆环上占一格。图标是里面前几个操作的小图标拼成的 2×2 缩略图（像手机桌面的文件夹），标签显示目录名和一个 ▸。
- 鼠标或拖动方向**停在目录上约 150 毫秒**，就在这个目录的外侧展开一段小圆弧，排着目录里的操作（最多 6 个），每个也带标签。
- 小圆弧的选法和主圆环一样：
  - 按住中键拖动：先拖到目录，等小圆弧展开，继续往外拖到某个操作上松开；
  - 圆环停在屏幕上时：指向目录展开，再点里面的操作；键盘上按目录的数字键展开，再按 1–6 选择；
  - 指针移回主圆环、移到别的格子，或按 Esc，小圆弧就收起。
- 小圆弧靠近屏幕边缘放不下时，自动换到另一侧展开。

**编辑**（设置 › Action Ring 的"固定操作"一节，改成一个可视化的圆环编辑器）：

- 编辑器画出和真实圆环一样的 8 个格子，可以直接拖动：
  - 把一个操作**拖到空格子**：移动它；
  - 拖到另一个操作上，**停留约 0.5 秒**（那个格子会放大提示）再松开：两个合成一个新目录，默认名"目录"，可以改名；
  - 拖到**已有目录**上：放进这个目录；
  - 点开目录，在目录里拖动：调整顺序；把操作**拖出目录**：放回圆环的空格子（没有空格子时不允许）；
  - 目录只剩一个操作时，自动解散成普通操作。
- "添加操作"按钮和现在一样，可以加到空格子里，也可以直接加进某个目录。
- 不方便拖动时也能用键盘：选中格子后，用按钮完成"移动""放入目录""移出目录"。

## 2. 规则

| 项 | 规则 |
|---|---|
| 层级 | 只有一层：目录里不能再放目录 |
| 每个目录最多 | 6 个操作（圆弧再长会挤，选起来容易误触） |
| 能放进目录的 | 固定操作。情境操作（选中文字、资源管理器相关）每次弹出都不一样，不能放进目录 |
| 情境操作的位置 | 不变：固定操作（含目录）占上下左右 4 格，情境操作占斜向 4 格。目录也算一个固定操作，所以最多 4 个"固定的格子"，每格可以是一个操作或一个目录 |
| 目录名 | 默认"目录"，在编辑器里点名称改；圆环上的标签显示名称 |
| 存储 | 存在 `config.json` 的 `ring` 里：固定格子从"操作 ID 列表"改成"格子列表"，每格是一个操作或一个目录（名称 + 操作 ID 列表）；旧配置自动迁移 |

## 3. 需要你决定

1. 情境操作不能放进目录，目录只有一层、每个最多 6 个操作，可以吗？
2. 固定格子维持 4 个（上下左右），每格可以是操作或目录，可以吗？还是希望能把 8 个格子都设成固定的（不要情境操作）？
3. 编辑放在设置页的可视化圆环编辑器里，可以吗？还是希望在真实的圆环上（比如按住某个键）直接拖？后者要处理"圆环不抢焦点"和拖动的冲突，复杂很多，我不推荐。
4. 停留多久展开：小圆弧 150 毫秒、编辑器里合成目录 0.5 秒，可以吗？
