# Action Ring 方案

> 状态：方案 v1 · 待你 review · 2026-10-21 · 对应需求 R116（见 [requirements.md](requirements.md)）
>
> 需求：增加一个 Action Ring（参考 Logitech Options+ 的 Actions Ring）：按鼠标中键弹出一圈操作，用情境感知（R25）展示当前可用的操作。

## 1. 用起来的样子

```
                 ▶ 播放/暂停
       📁 打开终端           📝 新建笔记
  😀 Emoji         ×            ✨ 问 AI
       ⬚ 截图               🔒 锁屏
                 ⚙ golauncher
```

- 在鼠标所在位置弹出一个圆环，最多 8 个按钮，中间是关闭按钮。
- **两种用法都支持**：
  - **按住中键 → 往某个方向拖 → 松开**：直接执行那个方向的操作（像 Logitech 和游戏里的轮盘，最快）；
  - **按住到弹出后松开** → 圆环留在屏幕上 → 再用鼠标点一个，或按数字键 1–8，Esc 或点圆环外关闭。
- 圆环出现时不抢走当前窗口的焦点：选中文字、当前窗口都还在，操作才能作用在它们上面。
- 鼠标移到某个按钮上时，外面显示它的名称（和图里一样的标签）。

## 2. 触发方式：不能直接吃掉中键

中键在很多程序里本来就有用：浏览器里**新标签页打开链接、关闭标签页、自动滚动**，终端和编辑器里粘贴，CAD 软件里平移视图。如果"按一下中键就弹出"并拦截这次点击，这些都会坏。

| 触发方式 | 说明 | 建议 |
|---|---|---|
| **按住中键约 0.3 秒**（默认） | 短按的中键照常传给程序（新标签页、关标签页都不受影响）；按住不放超过阈值才弹出圆环 | ✅ 默认 |
| Ctrl/⌘ + 中键 | 按住修饰键再点中键 | 可选 |
| 鼠标侧键（前进/后退键） | 不和中键冲突，但会占用浏览器的前进/后退 | 可选 |
| 键盘快捷键 | 在鼠标位置弹出，适合没有中键的触控板 | 可选 |

**按住中键的实现细节**：中键按下时先不放行，计时：
- 0.3 秒内松开 → 原样补发一次中键点击（按下 + 松开），程序收到的就是一次普通中键点击；
- 超过 0.3 秒 → 弹出圆环，这次按下不再传给程序；
- 按住中键拖动（比如浏览器的自动滚动、CAD 的平移）→ 一旦移动超过几个像素就立刻放行，不弹圆环。

**例外名单**：游戏、CAD、远程桌面、虚拟机等中键是核心操作的程序，可以在设置里加进例外名单，在它们里面完全不拦截。默认名单里预置常见的（远程桌面、VMware、Blender 等），全屏游戏默认也不拦截。

## 3. 圆环里显示什么

圆环有 8 个位置，分成两部分：

1. **固定操作**（用户自己挑，默认 4 个）：任何地方都显示，位置固定，方便形成肌肉记忆。默认：
   - 呼出 golauncher；
   - 问 AI；
   - 截图（调用系统截图：Windows 的 Win+Shift+S，macOS 的 ⌘⇧4）；
   - 锁屏。
2. **情境操作**（其余位置，自动填）：根据鼠标下面或前台的程序、选中的内容，从现有插件里挑最相关的：

| 情境 | 举例 |
|---|---|
| 有选中的文字（R63） | 翻译、AI 操作（包括你自定义的 AI 操作，R103）、网页搜索、复制 |
| 资源管理器 / 访达（R25） | 在这里打开终端、用 VS Code 打开、复制路径、新建文件 |
| 浏览器 | 用 AI 总结当前页（如果能拿到地址）、复制链接、在另一个浏览器打开 |
| 正在播放媒体 | 播放/暂停、下一首 |
| 其他 | 用户为某个程序单独配置的操作 |

情境操作复用现有插件的情境感知和选中文字的能力，插件不用为圆环单独写代码。用户也可以给某个程序单独配一组操作（"在微信里时显示这 4 个"）。

## 4. 设置（设置 › Action Ring，新的一页）

- 开关（**默认关闭**）
- 触发方式（§2）和按住的时长
- 固定操作：从所有命令和动作里挑，拖动排序
- 情境操作：开 / 关，最多几个
- 每个程序单独的操作
- 例外名单
- 外观：大小、跟随主题（深浅色、强调色）

## 5. 技术实现

| 部分 | Windows | macOS |
|---|---|---|
| 监听中键 | 低级鼠标钩子 `WH_MOUSE_LL`，跑在独立线程，回调必须很快返回（系统会摘掉超过约 300 毫秒的钩子） | `CGEventTap` 监听 `otherMouseDown/Up`，需要"辅助功能"权限（选中文字已经在用这个权限） |
| 补发短按的中键 | `SendInput` | `CGEventPost` |
| 圆环窗口 | MyGo 窗口：无边框、透明、置顶、不在任务栏、不抢焦点（`Frameless`、`Transparent`、`AlwaysOnTop`、`SkipTaskbar`、`Focusable: false`） | 同左（`Panel`） |
| 情境 | 鼠标下方的窗口（`WindowFromPoint`）+ 现有的情境感知 | 现有的情境感知 |

- 钩子只处理中键，其他鼠标事件原样放行，不记录、不保存任何鼠标轨迹。
- 已知限制：Windows 上以管理员身份运行的程序，普通权限的钩子收不到它窗口里的鼠标事件；在这类窗口里圆环不会弹出。
- 圆环的绘制、拖动方向判断、动画都在 MyGo 里做，跟随主题。
