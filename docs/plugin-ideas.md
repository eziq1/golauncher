# Windows 插件推荐清单

> 状态：讨论中 · 2026-10-15 · 对应问题 R30（见 [requirements.md](requirements.md)）
>
> 问题：在 Windows 上，还推荐开发什么插件？

排序原则：价值高、实现成本可控，并且能用上已有的平台能力。已有能力包括：环境感知（R25）、后台任务（R24）、动态刷新（M5 ①）、命令参数和 Form（M5 ②）、确认对话框、粘贴到前一个窗口。

## 第一梯队：天天会用，建议优先做

| 插件 | 功能 | 用上的已有能力 | 估计实现量 |
|------|------|----------------|------------|
| 系统命令与设置直达 | 锁屏、睡眠、重启、关机、注销、清空回收站、切换深浅色、静音；搜索直达系统设置页（`ms-settings:` 链接，中英文关键词） | 危险操作走确认 | 小 |
| 窗口切换器 | 搜索打开的窗口（标题、应用名、拼音），切换、关闭、移到另一个显示器 | 环境感知 | 中 |
| 网页搜索与快捷链接 | `g`、`bd`、`gh` 等前缀；自定义 `{query}` 模板；搜索 Chrome/Edge 书签 | 命令参数 | 小 |
| 文本片段（Snippets） | 保存常用文本，支持 `{date}`、`{clipboard}`、`{cursor}` 占位符，粘贴到当前窗口 | Form、粘贴 | 中 |
| 进程管理 | 搜索进程，查看 CPU 和内存占用，结束进程，打开所在位置；"结束当前前台应用" | 动态刷新、环境感知 | 中 |
| 开发者小工具 | UUID、哈希、Base64、URL 编解码、JSON 格式化、JWT 解码 | 根搜索直接出结果（和计算器一样） | 小 |
| Emoji 与符号 | 中英文关键词搜索 emoji 和特殊符号，粘贴 | 粘贴 | 小 |

## 第二梯队：很实用，实现稍复杂

| 插件 | 功能 |
|------|------|
| 窗口布局 | 左半屏、右半屏、居中、最大化、移到下一个显示器，可以绑定快捷键 |
| 最近的文件和项目 | 系统最近使用的文件；VS Code 和 JetBrains 最近打开的项目 |
| 终端配置与 WSL | Windows Terminal 的配置、WSL 发行版，直接打开 |
| 音频与媒体 | 切换默认的播放和录音设备、调音量、播放暂停和切歌 |
| 网络工具 | 本机 IP 和公网 IP、ping、DNS 查询、端口检测、查看已保存的 Wi-Fi 密码 |
| 计时器与番茄钟 | `timer 25m`，倒计时实时刷新，到点发通知（用后台任务和动态刷新） |
| 电源计划 | 在节能、平衡、高性能之间切换 |

## 第三梯队：需要先调研

| 插件 | 需要先确定的问题 |
|------|------------------|
| 翻译 | 选哪个接口：免费接口有数量限制，DeepL 需要 Key |
| 截图文字识别 | Windows 自带的 OCR（`Windows.Media.Ocr`），涉及 WinRT 调用 |
| 屏幕取色 | 需要做放大镜界面 |
| 快速笔记 / 待办 | 和现有的笔记工具怎么配合 |

## 建议

先做第一梯队的前三个：系统命令与设置直达、窗口切换器、网页搜索与快捷链接。可以由三个子代理在各自的 worktree 里并行开发。

**待你决定**：要做哪些、按什么顺序做。
